<p>第一种是按开放端口数。一个号码开几个端口就收几个的钱，适合需要多端口并行的场景。端口数固定时，成本完全可预测。</p>

<p>第二种是按端口占用时长。端口开多久算多久，适合长时间挂着但流量小的业务。这种方式对流量不敏感，对时间敏感。</p>

<p>第三种是按端口流量峰值。某些方案对单个端口的流量单独计量，超过阈值加价。这种方式本质上是流量计费加了一个端口维度。</p>

<p>三种适用场景里的第一种是多端口并行测试。需要同时从不同端口出站的场景，按端口计费比按流量计费更可控，也更好预算。</p>

<p>第二种是端口固定的长期业务。端口不变，成本可预测，预算好做，也不用每月算账单。</p>

<p>第三种是小流量多端口的场景。每个端口流量都很小，但端口数量多，按端口算比按流量算便宜，这种情况下按端口计费优势明显。</p>

<p>第二项是端口的复用规则。同一个端口能不能被多个时间段的业务复用，能不能释放后重新分配。复用规则宽松的方案，实际成本更低。</p>

<p>第三项是端口扩容的成本。加一个端口多少钱，有没有阶梯价，加得多会不会便宜。扩容成本决定了这个方案能不能长期用。</p>
